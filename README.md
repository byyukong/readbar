# 摸鱼阅读 · readbar

> 把小说塞进 VS Code 状态栏最左边那一行。不弹窗、不占编辑器、切窗口也看不出来。

支持 **txt / epub / mobi**，进度自动保存，下次打开接着读。

```
📖 第一章 开端 这里显示的是你正在读的那一页正文……            ⎇ main*  ⊗ 0  ⚠ 0
```

## 为什么是状态栏

- **藏在眼皮底下**：一行纯文本，混在「行 54, 列 1」「UTF-8」中间，路过的人只会以为你在看构建状态。
- **不打断写代码**：没有悬窗、没有新标签页、不抢焦点；翻页键只在打开书之后才生效，不会抢走编辑器里已有的 `Alt+]`。
- **真的能读**：按字符定位进度，关掉再开还在原处；章节正则识别「第 X 章」，三千章的书也能直接跳回当前位置。
- **一键隐身**：隐藏后进度冻结、翻页键失效，再显示回来接着读。

## 安装后三步

**1.** 状态栏最左边出现 `📖 摸鱼阅读 · 点击添加书籍`

**2.** 点它 → 「添加书籍」→ 选一个 txt / epub / mobi

**3.** `Alt+]` 翻页，或再点状态栏打开菜单

> 状态栏挤不下时，把「每行字数」调小，或调大「状态栏宽度」。

## 快捷键都能改

默认只占三个键，且全部可以在「键盘快捷方式」里重绑（`⌘K ⌘S`，搜「摸鱼阅读」）。
不想用默认键：把 `readbar.useDefaultKeys` 关掉，自己在 `keybindings.json` 里写任意组合：

```json
[
  { "key": "ctrl+alt+right", "command": "readbar.next" },
  { "key": "ctrl+alt+left",  "command": "readbar.prev" }
]
```

## 设置

设置项前缀是 `readbar`（扩展 ID 是 `kiryu.readbar`）。

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `readbar.statusBarAlign` | `left` | 文字靠左还是靠右 |
| `readbar.charsPerLine` | 40 | 每页最多多少字（上限） |
| `readbar.maxStatusWidth` | 720 | 文字最多占多少像素，0 = 不限制 |
| `readbar.showIcon` | true | 前面是否显示 📖 |
| `readbar.showPercent` | false | 末尾是否显示阅读百分比 |
| `readbar.keepFormat` | false | 保留原文换行（状态栏里仍会压成一行） |
| `readbar.useDefaultKeys` | true | 是否启用默认的 `Alt+] / Alt+[ / Alt+M` |
| `readbar.autoResume` | true | 启动后自动回到上次那本书 |
| `readbar.autoPageSeconds` | 0 | 自动翻页间隔，0 = 关闭 |

## 常见问题

**文字被窗口右边裁掉了？**
状态栏一行放不下这么多字，VS Code 不会省略，而是直接裁。把 `maxStatusWidth` 调小（默认 720），或把 `charsPerLine` 调小。

**想一次看更多字？**
把 `maxStatusWidth` 调大。窗口越宽能塞的字越多——但它同时会把右侧的行列号、编码等信息挤出去。

**隐藏之后找不回来了？**
`⌘⇧P` 搜「摸鱼阅读: 显示 / 隐藏状态栏」。

**书存在哪里？**
VS Code 的 `globalStorage` 下（`<User>/globalStorage/kiryu.readbar/readbar-db/`），一个 `db.json` 加附件目录。卸载扩展不会自动删，想彻底清就手动删这个目录。

**编码识别不准？**
用 `jschardet` 猜编码，置信度不够时回落 UTF-8。乱码的话先转成 UTF-8 再导入。

## 已知限制

- 状态栏只有**一行纯文本**，不能换行、没有富文本和排版。
- 只有键盘翻页，没有滚动条。
- 需要读取本地文件，**不能跑在 vscode.dev / 浏览器版**。
- mobi 解析为尽力而为，优先用 txt 或 epub。
